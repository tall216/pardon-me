# Alderinos — show notes

Canon and working notes for **Alderinos**, the show built with Cartoony. The
Director model and every episode build read this folder. It is versioned with
the rest of the repo.

## The premise (CONFIRMED)

- The show is called **Alderinos**.
- It is based around **Alderinos Pub & Pasta**, a bar and restaurant.
- It is set in the **Collinwood** neighborhood of **Cleveland, Ohio**, **circa 1999**.
- Approved characters so far: **Uncle D**, **Winston**, **Ariana**, and
  **the owner** (a cartoon version of the show's creator). Uncle D and Winston
  have a data sheet in the Cartoony pipeline. Winston's first look and outfits
  are in progress.
- **Quail Hollow** is in the pipeline as a drawing set; its role in the show
  has not been stated yet.
- The pipeline, the data sheet, the framing rules, and `LESSONS.md` live on the
  owner's computer, in the Cartoony working folder, not in this repo. These
  notes should be moved next to them.

## How these notes work

Facts are tagged:

| Tag | Meaning |
| --- | --- |
| `CONFIRMED` | From the owner or the pipeline. Canon. |
| `IDEA` | Spitballed, not yet locked. Director may use it but must flag it. |
| `OPEN` | Undecided. Director writes around it. |

Spitball goes into `spitball.md` first. When an idea is locked, it moves into
the right file and gets `CONFIRMED`. The character sheet always wins over the
notes on anything visual.

## Files

| File | Holds |
| --- | --- |
| `spitball.md` | The inbox. Loose ideas in the order they came. |
| `world.md` | Collinwood, Cleveland, 1999: what is real and what the show says. |
| `places.md` | Alderinos Pub & Pasta and everywhere else the show goes. |
| `characters/` | One file per character. `_cast.md` is the one-line roster. |
| `rules-of-the-show.md` | Format, tone, physics. Mostly `OPEN` until decided. |
| `continuity-log.md` | Facts episodes have put on screen. Append-only. |
| `episodes/TEMPLATE.md` | What each episode file records. |

## Director reading order

1. `rules-of-the-show.md`
2. `world.md`, `places.md`
3. `characters/` for whoever is in the episode, plus `_cast.md`
4. `continuity-log.md`, newest first
5. `spitball.md` only for ideas tagged as usable
