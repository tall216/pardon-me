# Continuity log

Append-only. Every fact an episode establishes on screen goes here with the
episode it came from. The Director reads this from the bottom up before
planning. Edit an entry only to correct a transcription error; to retire a
fact, add a new entry saying so and why.

Format: `- [SxxEyy] <fact>. (<file in lore/ that should be updated, if any>)`

## Season 1
