# Pardon Me — assets

## ringtone.wav (bundled default)
- A synthesized classic telephone dual-tone ring (440 Hz + 480 Hz), generated by
  `scripts/gen_ringtone.py` (Python stdlib only, no dependencies).
- ~1.5 MB, 44.1 kHz mono WAV.
- Wired as the default ringtone via `require('../assets/ringtone.wav')` in
  `src/fakeCall.ts`, and as the call-channel sound in `src/scheduler.ts`.

## Swap it for your own
Replace `ringtone.wav` with any Expo-supported format (`.mp3`/`.wav`/`.m4a`) and
update the `require` in `src/fakeCall.ts` (and the `sound` field in
`ensureCallChannel` in `src/scheduler.ts`).

## Regenerate
```
python scripts/gen_ringtone.py
```
